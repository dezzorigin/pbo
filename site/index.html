Kenapa contoh ini cukup

Satu konsep PBO, satu contoh yang bisa dibaca habis dalam sekali duduk — dan benar-benar jalan.

Inheritance sungguhan

CylinderS extends Circle: radius, warna, dan getArea() diwarisi — tidak ditulis ulang. Volume memakai super.getArea() × height.

Enkapsulasi rapi

Field privat (radius, color, height) diekspos lewat getter/setter. Konstruktor default + custom di kedua kelas.

Angka yang bisa dicek

Volume = π × r² × h. Silinder 1: π × 1² × 10 = 31,4159… Silinder 2: π × 7² × 15 = 2309,0706… CI memverifikasi keduanya tiap push.

Cara kerja

Tiga langkah, tanpa build tool, tanpa dependensi.

1

Compile

Semua file dikompilasi ke folder out/.

javac -d out *.java
2

Jalankan

Main membuat dua silinder dan mencetak volumenya.

java -cp out Main
3

Cek angka

Bandingkan output dengan rumus π × r² × h. Atau biarkan CI yang mengeceknya.

./run.sh

Intinya ada di sini

CylinderS.java — seluruh "inheritance"-nya terjadi di file ini.

public class CylinderS extends Circle {
    private double height;

    // konstruktor default: radius 1.0 dari super(), tinggi 10.0
    public CylinderS() {
        super();
        this.height = 10.0;
    }

    public CylinderS(double r, double h) {
        super(r);
        this.height = h;
    }

    public double getVolume() {
        return super.getArea() * this.height;
    }
}
